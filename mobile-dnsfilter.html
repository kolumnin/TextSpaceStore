Mobile DNS Filter

A small, offline-friendly launcher for the clean personalDNSfilter profile.

Install on this phone

  1. Download the clean profile.
  2. Open it with personalDNSfilter and choose Import/Restore.
  3. Turn off Android Private DNS before starting the filter.
  4. Start the DNS proxy and confirm that the app shows it as running.
